# Changelog / 修改记录

## 0.1.0 — 2026-10-25

- Added separate Chinese and English architecture, upgrade, runtime, configuration, troubleshooting, lessons and distribution guides.
- Added explicit-path commands for the local Bun installation; separated platform runtimes from private runtimes.
- Added six scoped scripts: inspect, exact-release fetch, cold backup/compare, explicit core install, Node staging and local health.
- Added offline boundary tests and CI. No new production operations performed.
- Sanitized the public material: no personal instructions, live credentials, actual cron identifiers, private receipt archives or business directories.
- Kept dangerous/version-dependent wrapper patches as a documented register rather than an unconditional installer.
